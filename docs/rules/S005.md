# S005: nonzero-in-loop

Status: preview. Enable with `--preview --select S005`.

CUDA nonzero() inside a loop synchronizes with the host.

PyTorch nonzero on a CUDA tensor requires host-device synchronization. Static analysis does not measure its cost.

## Boundaries and manual review

Only confirmed CUDA inputs to torch.nonzero or Tensor.nonzero are checked. CPU and unknown devices are excluded.

Review whether nonzero indices are needed on every iteration.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/generated/torch.nonzero.html) (API reference checked during v0.2 development).
