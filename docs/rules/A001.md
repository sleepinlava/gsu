# A001: retain-graph-in-loop

Status: preview. Enable with `--preview --select A001`.

Explicit graph retention inside a loop may keep unnecessary autograd state.

retain_graph=True retains the graph after differentiation. Multiple backward passes may require it.

## Boundaries and manual review

Checks Tensor.backward and torch.autograd.backward/grad with explicit retain_graph=True. create_graph must be absent or explicitly False; True and unknown values are excluded.

Review graph retention while preserving repeated backward requirements.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/generated/torch.Tensor.backward.html) (API reference checked during v0.2 development).
