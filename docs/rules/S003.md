# S003: tolist-in-loop

Status: preview. Enable with `--preview --select S003`.

Tensor.tolist() inside a loop may transfer data to the CPU.

Tensor.tolist() converts values into Python objects and moves data to the CPU if necessary.

## Boundaries and manual review

Retain conversions required by consumers. Known CPU tensors are excluded; an unknown device is only medium confidence.

Review whether conversion can be performed less frequently.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/generated/torch.Tensor.tolist.html) (API reference checked during v0.2 development).
