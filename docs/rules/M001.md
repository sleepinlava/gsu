# M001: empty-cache-in-loop

Status: preview. Enable with `--preview --select M001`.

CUDA cache clearing inside a loop may impair allocator reuse.

empty_cache releases unoccupied cached memory. Repeated clearing may prevent reuse; fragmentation or sharing memory with other applications may justify it.

## Boundaries and manual review

Recognizes torch.cuda.empty_cache and torch.cuda.memory.empty_cache with no arguments. It does not claim that clearing is always wrong or that it increases memory available to PyTorch.

Review whether cache clearing is necessary on every iteration.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/generated/torch.cuda.memory.empty_cache.html) (API reference checked during v0.2 development).
