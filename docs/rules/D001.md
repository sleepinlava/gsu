# D001: hardcoded-device

CUDA device index is hardcoded.

## Trigger and boundaries

A supported device constructor, Tensor conversion, or factory device argument uses a fixed nonnegative CUDA index. Statically propagated constants are reported at their original literal, once per location. Plain strings, dynamic indices, and CPU devices are excluded.

## Explanation

A fixed CUDA index may restrict device configuration or portability; it is not inherently a performance defect.

## Manual suggestion

Review whether this device index should come from the application's existing configuration.

```python
import torch
device = torch.device("cuda:0")
x = torch.zeros(4, device="cuda:1")
message = "cuda:0"              
chosen = torch.device("cuda")    
```
