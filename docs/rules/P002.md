# P002: repeated-dtype-cast

Potential repeated dtype conversion inside a loop.

## Trigger and boundaries

A confirmed Tensor requests a supported explicit dtype conversion in a repeated context. A different known source dtype gives high confidence; unknown source or annotated Tensor gives medium. Same known dtype, device-only calls, and calls outside loops are excluded.

## Explanation

This cast may convert tensor values during each iteration. The required input precision is not inferred.

## Manual suggestion

Review whether the input dtype can be prepared earlier while preserving numerical behavior and per-batch requirements.

```python
import torch
x = torch.ones(4, dtype=torch.float64)
for i in range(10):
    y = x.float()

z = torch.ones(4, dtype=torch.float32)
for i in range(10):
    y = z.float()
```

GSU does not execute this code, measure performance, or automatically modify it.
