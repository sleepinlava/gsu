# M003: accumulating-cat-in-loop

Status: preview. Enable with `--preview --select M003`.

Accumulating a tensor with cat inside a loop may repeatedly allocate and copy.

The visible assignment concatenates the previous accumulator into its replacement. Shapes, iteration counts and runtime cost are unknown.

## Boundaries and manual review

Only a direct straight-line loop assignment acc = torch.cat([acc, part], ...) with a Tensor initialized outside the loop is supported. Other writes, aliases, control flow and escaping uses are excluded. This is a potential pattern, not a proof of quadratic runtime.

Consider collecting parts and concatenating once if intermediate results are unnecessary.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/generated/torch.cat.html) (API reference checked during v0.2 development).
