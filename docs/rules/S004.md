# S004: scalar-conversion-in-loop

Status: preview. Enable with `--preview --select S004`.

Python scalar conversion inside a loop may synchronize with the host.

Converting a CUDA tensor with bool, int or float may require waiting for device work.

## Boundaries and manual review

Only unshadowed builtins and confirmed tensors are recognized. Known CPU tensors are excluded. No tensor shape or runtime validity is inferred.

Review whether scalar conversion can be performed less frequently.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/tutorials/recipes/recipes/tuning_guide) (API reference checked during v0.2 development).
