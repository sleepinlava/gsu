# A002: anomaly-detection-enabled

Status: preview. Enable with `--preview --select A002`.

Autograd anomaly detection adds debugging overhead.

Anomaly detection performs additional debugging checks that slow execution. It may be intentional during debugging.

## Boundaries and manual review

Checks detect_anomaly and set_detect_anomaly(True), including context-manager calls. Explicit False or dynamic enable switches are excluded. Each call is reported once.

Keep anomaly detection enabled when debugging requires it.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/autograd.html) (API reference checked during v0.2 development).
