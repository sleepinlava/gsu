# D002: repeated-device-cast

Repeated conversion to the same known device.

## Trigger and boundaries

A confirmed Tensor has consecutive equivalent device conversions to the same CPU or fixed CUDA index. There must be no intervening use, unknown call, copy=True, dtype change, or explicit memory_format. A factory followed by one conversion is insufficient. Unspecified current CUDA devices are excluded.

## Explanation

This conversion appears redundant. It may return the existing tensor rather than copying data.

## Manual suggestion

Review whether the repeated conversion is needed to express an API boundary or defensive device handling.

```python
import torch
x = torch.ones(4, device="cpu")
y = x.to("cuda:0").to("cuda:0")
z = x.to("cuda:0").to("cuda:1")
w = x.to("cuda:0").to("cuda:0", copy=True)
```

GSU does not execute this code, measure performance, or automatically modify it.
