# S001: item-in-loop

Tensor scalar extraction inside a loop may synchronize with the host.

## Trigger and boundaries

A confirmed Tensor calls item() without arguments in a repeated context. CUDA gives high confidence; unknown device or an annotated Tensor gives medium confidence. Known CPU tensors, ordinary objects, and calls outside loops are excluded.

## Explanation

Reading a CUDA tensor as a Python scalar may require waiting for device work.

## Manual suggestion

Review whether scalar reads can be less frequent or aggregated without changing control flow or logging requirements.

```python
import torch
loss = torch.ones((), device="cuda")
for step in range(10):
    print(loss.item())

cpu_value = torch.ones((), device="cpu")
for step in range(10):
    print(cpu_value.item())
```
