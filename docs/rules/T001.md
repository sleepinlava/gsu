# T001: transfer-in-loop

Potential device transfer inside a loop.

## Trigger and boundaries

A confirmed Tensor is converted between CPU and CUDA, or between known CUDA indices, in a repeated context. Unknown source device permits medium confidence for a CUDA target. Known same-device conversions and dtype-only casts are excluded.

## Explanation

This conversion may transfer tensor data during each iteration. Static analysis does not measure its cost.

## Manual suggestion

Review whether the transfer is necessary for each batch. Move it earlier only if the data and device requirements remain valid.

```python
import torch
x = torch.ones(4, device="cpu")
for i in range(10):
    y = x.to("cuda")

z = torch.ones(4, device="cuda:0")
for i in range(10):
    z = z.to("cuda:0")
```
