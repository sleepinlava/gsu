# M002: tensor-copy-in-loop

Status: preview. Enable with `--preview --select M002`.

Constructing a tensor from a tensor inside a loop copies its data.

torch.tensor(existing_tensor) creates a new leaf tensor and copies data. The copy and detachment may be intentional.

## Boundaries and manual review

Requires a confirmed Tensor data argument. Do not replace this blindly with as_tensor or detach: storage aliasing, device, dtype and autograd semantics can change. detach().clone() still copies.

Review whether an independent copy is required on every iteration.

Severity: medium. Confidence describes static evidence, not measured impact. No automatic fix is provided.

[PyTorch documentation](https://docs.pytorch.org/docs/2.12/generated/torch.tensor.html) (API reference checked during v0.2 development).
