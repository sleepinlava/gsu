# P001: explicit-float64

Explicit float64 tensor precision; review whether it is required.

## Trigger and boundaries

A supported Tensor factory or conversion explicitly requests float64 / torch.double. Ordinary Python floats, unknown objects, implicit defaults, and global dtype-setting calls are excluded. FP64 may be necessary for numerical correctness.

## Explanation

Float64 is explicitly requested. Its cost and necessity depend on hardware and numerical requirements.

## Manual suggestion

Validate numerical accuracy and performance before choosing a lower precision.

```python
import torch
x = torch.ones(4, dtype=torch.float64)
x = x.double()                      
value = float(1)                    
z = torch.ones(4)                   
```
